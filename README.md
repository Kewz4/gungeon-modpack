# Gungeon modpack updates

Our Enter the Gungeon modpack checks `manifest.txt` here every time the game starts and downloads any of these
files that changed, so everyone stays on the same version. Nothing to do by hand.

- `BepInEx/plugins/Local-ModpackFixes`: character quests, Ammonomicon pages, controller and online co-op fixes
- `BepInEx/plugins/Local-FastLoad` and `BepInEx/patchers/Local-FastLoad`: faster loading, loading window, this updater
- `BepInEx/plugins/Local-Modpack_Tips`: item tips
- `BepInEx/plugins/Hero88go-GungeonOnline`: Enter The Gungeon Online Co-Op Mod by Hero88go, unchanged, MIT license
  (see THIRD-PARTY.md). Original: https://github.com/Hero88go/GungeonOnlineCoOpMod
